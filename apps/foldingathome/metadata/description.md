# Foldingathome (LinuxServer.io)

Folding@home é um projeto de computação distribuída para simulação da dinâmica de proteínas, incluindo o processo de dobramento de proteínas e os movimentos de proteínas envolvidas em diversas doenças. Ele reúne cientistas cidadãos que se voluntariam para executar simulações da dinâmica de proteínas em seus computadores pessoais. Os insights obtidos a partir desses dados estão ajudando os cientistas a compreender melhor a biologia e proporcionando novas oportunidades para o desenvolvimento de terapias.
