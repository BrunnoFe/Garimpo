# PyLoad

pyLoad é um gerenciador de download gratuito e de código aberto escrito em Python e projetado para ser extremamente leve, facilmente extensível e totalmente gerenciável via web.

## Antes de instalar

Conta Padrão

| Usuário | Senha |
|----------|----------|
| `pyload`    | `pyload` |

 Diretório padrão no Pyload

| Nome | Valor |
| ---- | ----- |
| Diretório de Download | `/DATA/Downloads` |

---

Convertido automaticamente da loja CasaOS (https://github.com/IceWhaleTech/CasaOS-AppStore, licença Apache-2.0) pelo Garimpo do BrunOS. Pastas: os dados do app ficam na pasta do app no Runtipi; filmes, músicas, fotos e downloads, na pasta de mídia do Runtipi. Problemas com o app em si: fale com o autor dele.
