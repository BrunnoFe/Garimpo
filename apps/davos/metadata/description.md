# Davos (LinuxServer.io)

O Davos é uma ferramenta de automação de FTP que verifica periodicamente locais de hospedagem específicos em busca de novos arquivos. Ele pode ser configurado para diversas finalidades, incluindo a detecção de arquivos específicos que aparecem no local de hospedagem, para que possa ser baixado e, se necessário, movido. Também oferece suporte a notificações de conclusão e chamadas de API subsequentes para otimizar o fluxo de trabalho.
