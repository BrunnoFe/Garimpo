# Kasm (LinuxServer.io)

O Kasm Workspaces é uma plataforma de streaming de contêineres Docker para fornecer acesso baseado em navegador a desktops, aplicativos e serviços web. O Kasm utiliza Infraestrutura de Desktop Contêinerizada (CDI) habilitada para DevOps para criar contêineres Docker descartáveis e sob demanda, acessíveis via navegador web. Exemplos de casos de uso incluem Isolamento Remoto de Navegador (RBI), Prevenção de Perda de Dados (DLP), Desktop como Serviço (DaaS), Serviços de Acesso Remoto Seguro (RAS) e coleta de Inteligência de Fontes Abertas (OSINT). A renderização dos contêineres com interface gráfica é feita pelo projeto de código aberto KasmVNC.

## Requer privilégios

A receita deste app pede poderes sobre o servidor que os apps comuns não têm. Instale só se confia nele:

- Mexe na pasta /dev/input do servidor
- Mexe na pasta /run/udev/data do servidor
