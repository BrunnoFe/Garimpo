# Mullvad browser (LinuxServer.io)

O Mullvad Browser é um navegador web focado em privacidade, desenvolvido em colaboração entre a Mullvad VPN e o Projeto Tor. Ele foi projetado para minimizar o rastreamento e a identificação do usuário. Pode-se dizer que é um navegador Tor para usar sem a rede Tor. Em vez disso, você pode usá-lo com uma VPN confiável.

## Requer privilégios

A receita deste app pede poderes sobre o servidor que os apps comuns não têm. Instale só se confia nele:

- Poderes de administrador do Linux (NET_ADMIN)
