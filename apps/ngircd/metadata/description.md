# Ngircd (LinuxServer.io)

O Ngircd é um servidor IRC gratuito, portátil e leve para redes pequenas ou privadas, desenvolvido sob a Licença Pública Geral GNU (GPL). É fácil de configurar, suporta endereços IP dinâmicos e IPv6, conexões protegidas por SSL e PAM para autenticação. Foi escrito do zero e não é baseado no IRCd original.
