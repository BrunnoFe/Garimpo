# Xbackbone (LinuxServer.io)

Xbackbone é um gerenciador de arquivos PHP simples, auto-hospedado e leve, compatível com a ferramenta de compartilhamento instantâneo ShareX e sistemas *NIX. Ele permite o upload e a exibição de imagens, GIFs, vídeos, código, texto formatado, além de download e upload de arquivos. Possui também uma interface web com gerenciamento de múltiplos usuários, histórico de uploads e suporte a busca.
