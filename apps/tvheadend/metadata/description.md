# Tvheadend (LinuxServer.io)

O Tvheadend funciona como um servidor proxy: é um servidor de streaming e gravador de TV para Linux, FreeBSD e Android, compatível com DVB-S, DVB-S2, DVB-C, DVB-T, ATSC, ISDB-T, IPTV, SAT>IP e HDHomeRun como fontes de entrada. O Tvheadend oferece streaming via HTTP (VLC, MPlayer), HTSP (Kodi, Movian) e SAT>IP. Múltiplas fontes de EPG são suportadas (DVB e ATSC via antena, incluindo extensões OpenTV DVB, XMLTV e PyXML).

## Requer privilégios

A receita deste app pede poderes sobre o servidor que os apps comuns não têm. Instale só se confia nele:

- Acesso ao aparelho /dev/dvb do servidor
