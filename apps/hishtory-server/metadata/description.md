# Hishtory server (LinuxServer.io)

O hiSHtory é um histórico de shell aprimorado. Ele armazena seu histórico de shell em contexto (em qual diretório você executou o comando, se ele foi bem-sucedido ou falhou, quanto tempo levou, etc.). Tudo isso é armazenado localmente e criptografado de ponta a ponta para sincronização com todos os seus outros computadores.
