# Netbox (LinuxServer.io)

O Netbox é uma ferramenta de gerenciamento de endereços IP (IPAM) e gerenciamento de infraestrutura de data center (DCIM). Inicialmente concebido pela equipe de engenharia de redes da DigitalOcean, o Netbox foi desenvolvido especificamente para atender às necessidades de engenheiros de rede e infraestrutura. Ele foi projetado para funcionar como uma fonte de verdade específica para operações de rede.
