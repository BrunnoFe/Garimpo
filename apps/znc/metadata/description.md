# Znc (LinuxServer.io)

Znc é um bouncer de rede IRC ou BNC. Ele pode desconectar o cliente do servidor IRC real e também de canais selecionados. Vários clientes de diferentes locais podem se conectar simultaneamente a uma única conta ZNC e, portanto, aparecer com o mesmo apelido no IRC.
