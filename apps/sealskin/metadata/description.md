# Sealskin (LinuxServer.io)

O Sealskin é uma plataforma cliente-servidor autohospedada que permite aos usuários executar aplicativos de desktop poderosos e conteinerizados, transmitidos diretamente para um navegador da web. Ele usa uma extensão do navegador para interceptar as ações do usuário — como clicar em um link ou baixar um arquivo — e redirecioná-lo para um ambiente de aplicativo seguro e isolado, executado em um servidor remoto.

## Requer privilégios

A receita deste app pede poderes sobre o servidor que os apps comuns não têm. Instale só se confia nele:

- Controla o Docker do servidor (socket do Docker): equivale a controle total
