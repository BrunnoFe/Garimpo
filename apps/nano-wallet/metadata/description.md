# Nano wallet

A Nano-wallet é um protocolo de pagamento digital projetado para ser acessível e leve, com foco na eliminação das ineficiências presentes em outras criptomoedas. Com transações ultrarrápidas e taxas zero em uma rede segura, ecológica e descentralizada, a Nano se torna ideal para transações do dia a dia. Este contêiner é um wrapper nginx simples para a carteira leve localizada aqui. Você precisará fornecer um host RPC válido ao acessar este contêiner.
