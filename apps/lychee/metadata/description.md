# Lychee (LinuxServer.io)

O Lychee é uma ferramenta gratuita de gerenciamento de fotos que funciona no seu servidor ou espaço web. A instalação leva apenas alguns segundos. Faça upload, gerencie e compartilhe fotos como se estivesse usando um aplicativo nativo. O Lychee vem com tudo o que você precisa e todas as suas fotos são armazenadas com segurança.
