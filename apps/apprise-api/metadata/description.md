# Apprise api (LinuxServer.io)

A API do Apprise aproveita os recursos do Apprise em sua rede com uma API fácil de usar. * Envie notificações para mais de 100 serviços. * Um gateway incrivelmente leve para o Apprise. * Um microsserviço pronto para produção à sua disposição. * Um site simples para verificar e testar sua configuração. A API do Apprise foi projetada para se integrar facilmente a ecossistemas existentes (e novos) que buscam uma solução de notificação simples.
