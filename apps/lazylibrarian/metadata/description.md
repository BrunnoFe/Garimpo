# Lazylibrarian (LinuxServer.io)

Lazylibrarian é um programa para seguir autores e obter metadados para todas as suas necessidades de leitura digital. Ele usa uma combinação do Goodreads Librarything e, opcionalmente, do Google Books como fontes de informações sobre autores e livros. Este contêiner é baseado no fork DobyTang.
