# Scummvm (LinuxServer.io)

ScummVM é um programa que permite executar certos jogos clássicos de aventura gráfica e RPG, desde que você já possua os arquivos de dados dos jogos. A genialidade do programa reside no fato de que o ScummVM simplesmente substitui os executáveis originais dos jogos, permitindo jogá-los em sistemas para os quais eles nunca foram projetados! O ScummVM é uma reescrita completa dos executáveis desses jogos e não um emulador.
