# Openvscode server

O Openvscode-server fornece uma versão do VS Code que executa um servidor em uma máquina remota e permite o acesso por meio de um navegador web moderno.

## Requer privilégios

A receita deste app pede poderes sobre o servidor que os apps comuns não têm. Instale só se confia nele:

- Mexe na pasta / do servidor
