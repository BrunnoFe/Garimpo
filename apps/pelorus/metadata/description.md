# Pelorus (LinuxServer.io)

Pelorus é um navegador de IA para desktops Linux com Selkies. Pelorus executa um servidor FastAPI que permite a um agente LLM (Ollama, compatível com OpenAI ou Gemini) controlar o mouse, o teclado, a captura de tela e o gerenciamento de janelas por meio do backend de uso do computador Pixelflux, uma árvore de acessibilidade do Linux (AT-SPI) e integração opcional com o KWin D-Bus.
