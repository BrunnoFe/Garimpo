# Ombi (LinuxServer.io)

O Ombi permite que você hospede seu próprio sistema de gerenciamento de solicitações e usuários do Plex. Se você compartilha seu servidor Plex com outros usuários, permita que eles solicitem novos conteúdos usando uma interface fácil de usar! Gerencie todas as suas solicitações de filmes e séries com facilidade, deixe recados para os usuários e receba notificações quando um usuário solicitar algo. Permita que seus usuários relatem problemas com suas solicitações para que você saiba se há algum problema com o áudio, por exemplo. Você pode até enviar newsletters semanais automáticas com os novos conteúdos adicionados ao seu servidor Plex!
