# Pidgin (LinuxServer.io)

Pidgin é um programa de bate-papo que permite que você acesse contas em várias redes de bate-papo simultaneamente. Isso significa que você pode estar conversando com amigos no XMPP e participando de um canal IRC ao mesmo tempo.
