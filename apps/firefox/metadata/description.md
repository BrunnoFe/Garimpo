# Firefox (LinuxServer.io)

O Firefox Browser, também conhecido como Mozilla Firefox ou simplesmente Firefox, é um navegador web gratuito e de código aberto desenvolvido pela Mozilla Foundation e sua subsidiária, a Mozilla Corporation.
