# Habridge (LinuxServer.io)

O Habridge emula a API do Philips Hue para outros gateways de automação residencial, como o Amazon Echo/Dot de 1ª geração (a 2ª geração apresenta problemas para detectar o ha-bridge) ou outros sistemas compatíveis com o Philips Hue. O Bridge processa comandos básicos, como ligar, desligar e ajustar o brilho, do protocolo Hue. Este bridge pode controlar a maioria dos dispositivos que possuem uma API própria.
