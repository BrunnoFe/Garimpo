# Darktable (LinuxServer.io)

O darktable é um aplicativo de código aberto para fluxo de trabalho fotográfico e revelação de arquivos RAW. Uma mesa de luz e câmara escura virtuais para fotógrafos. Ele gerencia seus negativos digitais em um banco de dados, permite visualizá-los através de uma mesa de luz com zoom e possibilita revelar e aprimorar imagens RAW.
