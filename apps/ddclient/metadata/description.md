# Ddclient (LinuxServer.io)

O Ddclient é um cliente Perl usado para atualizar entradas de DNS dinâmico para contas em provedores de serviços de rede DNS dinâmico. Foi originalmente escrito por Paul Burry e agora é mantido principalmente por wimpunk. Ele tem a capacidade de atualizar mais do que apenas o DNS dinâmico e pode obter seu endereço IP WAN de várias maneiras diferentes.
