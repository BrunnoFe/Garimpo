# Steamos

SteamOS é uma distribuição Linux baseada em Arch, criada pela Valve Software. Este contêiner é uma instalação padrão do Arch com os repositórios do Steam adicionados para suporte a softwares. Este contêiner funcionará apenas com GPUs AMD/Intel modernas em um host Linux real.

## Requer privilégios

A receita deste app pede poderes sobre o servidor que os apps comuns não têm. Instale só se confia nele:

- Mexe na pasta /dev/input do servidor
- Mexe na pasta /run/udev/data do servidor
