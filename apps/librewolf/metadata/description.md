# Librewolf (LinuxServer.io)

O LibreWolf é uma versão personalizada e independente do Firefox, com os objetivos principais de privacidade, segurança e liberdade do usuário. O LibreWolf também visa remover toda a telemetria, coleta de dados e incômodos, além de desativar recursos que restringem a liberdade, como o DRM.
