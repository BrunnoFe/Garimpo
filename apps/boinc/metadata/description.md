# Boinc (LinuxServer.io)

O BOINC é uma plataforma para computação de alto desempenho em larga escala (milhares ou milhões de computadores). Pode ser usado para computação voluntária (utilizando dispositivos de consumo) ou computação em grade (utilizando recursos organizacionais). Suporta aplicações virtualizadas, paralelas e baseadas em GPU.
