# Ldap auth (LinuxServer.io)

O software Ldap-auth serve para autenticar usuários que solicitam recursos protegidos de servidores proxyados pelo nginx. Ele inclui um daemon (ldap-auth) que se comunica com um servidor de autenticação e um daemon de servidor web que gera um cookie de autenticação com base nas credenciais do usuário. Os daemons são escritos em Python para uso com um servidor de autenticação LDAP (Lightweight Directory Access Protocol) (OpenLDAP ou Microsoft Windows Active Directory 2003 e 2012).
