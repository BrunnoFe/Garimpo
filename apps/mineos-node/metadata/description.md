# MineOS

MineOS é uma interface de servidor para facilitar a gestão de tarefas administrativas do Minecraft. Esta iteração usando o Node.js visa aprimorar os scripts anteriores do MineOS (baseados em Python), aproveitando o modelo assíncrono de acionamento de eventos do Node.JS e websockets.

## Antes de instalar

Conta padrão

| Nome de usuário | Senha |
|----------|----------|
| `mc`    | `root` |

A receita original vinha com uma senha fixa (igual para todo mundo); aqui você escolhe a sua na instalação.

## Requer privilégios

A receita deste app pede poderes sobre o servidor que os apps comuns não têm. Instale só se confia nele:

- Mexe na pasta /var/games/mineos/minecraft do servidor
