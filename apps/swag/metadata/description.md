# Swag (LinuxServer.io)

SWAG - Secure Web Application Gateway (anteriormente conhecido como letsencrypt, sem relação com Let's Encrypt™) configura um servidor web Nginx e um proxy reverso com suporte a PHP e um cliente Certbot integrado que automatiza os processos de geração e renovação de certificados SSL gratuitos (Let's Encrypt e ZeroSSL). Também inclui o fail2ban para prevenção de intrusões.
