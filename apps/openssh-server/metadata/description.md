# Openssh server (LinuxServer.io)

O OpenSSH Server é um ambiente isolado (sandbox) que permite acesso SSH sem fornecer as chaves de acesso ao servidor inteiro. Conceder acesso SSH por meio de uma chave privada geralmente significa conceder acesso total ao servidor. Este contêiner cria um ambiente limitado e isolado ao qual outros usuários podem acessar via SSH. Os usuários têm acesso apenas às pastas mapeadas e aos processos em execução dentro deste contêiner.
