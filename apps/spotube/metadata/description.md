# Spotube (LinuxServer.io)

O Spotube é um cliente Spotify de código aberto e multiplataforma, compatível com diversas plataformas, que utiliza a API de dados do Spotify e o YouTube, Piped.video ou JioSaavn como fonte de áudio, eliminando a necessidade do Spotify Premium.
