# Remmina (LinuxServer.io)

Remmina é um cliente de área de trabalho remota escrito em GTK, projetado para ser útil a administradores de sistemas e viajantes que precisam trabalhar com vários computadores remotos em frente a telas grandes ou pequenas. Remmina suporta múltiplos protocolos de rede, em uma interface de usuário integrada e consistente. Atualmente, os protocolos suportados são RDP, VNC, SPICE, SSH e EXEC.
